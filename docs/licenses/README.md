# Dependency license texts

These files apply to dependencies, not to Didanihaa's own source-code license.

- `dotnet-MIT.txt`: unmodified license from Microsoft.NETCore.App.Runtime.win-x64 11.0.0; also used by the MIT-licensed .NET components identified in THIRD_PARTY_NOTICES.md.
- `SQLitePCLRaw-Apache-2.0.txt`: unmodified upstream text from SQLitePCL.raw commit `ed046114d5a30534e13294d94d78eb73de896ad4`, associated with the pinned 3.0.5 core/provider packages. Their copyright attribution is recorded in THIRD_PARTY_NOTICES.md.
- `SQLite-Public-Domain.txt`: unmodified statement from the SQLite 3.53.4 NuGet package.

Build-Publish preserves additional package/runtime notices from the restored packages. Browser dependency notices and the font's OFL remain beside their respective assets. Review this directory and THIRD_PARTY_NOTICES.md when upgrading dependencies.
